# Danceability, Energy, and Song Popularity Analysis

Final Project for DSC 80 @ UCSD using Spotify Dataset
by Scarlett Jeffries

## Introduction
Using a dataset from Spotify, this project aims to use danceability and energy scores to predict the popularity of a song. I enjoy upbeat and lively music, so I am interested in exploring the impact of these factors on a song's popularity. Further, I am interested in understanding whether this relationship is counfounded by the popularity of the artist or genre of the song.
